# 打卡 · Web 版

每日任务清单，纯静态网页，一个 index.html 装下全部界面和逻辑。

数据存在浏览器本地，**不联网、不注册、不上传**。没有任何后端。

在线地址：<https://xing-patrick.github.io/daka-pwa/>

直接把这个链接发人就行——谁打开都用自己的浏览器存，各存各的，互相看不到。

---

## 在手机上装成一个 App

必须经 http(s) 打开——直接双击本地文件不行，那样拿不到离线缓存和主屏安装。

**iPhone / Safari**

1. 用 Safari 打开上面的地址（微信、QQ 的内置浏览器不行，要复制到 Safari）
2. 点底部中间的「分享」按钮
3. 选「添加到主屏幕」，点右上角「添加」
4. 回到桌面，用新出现的图标打开

从主屏图标打开后，设置页的「运行方式」会显示 **独立 App**、「本地存储」显示 **持久**。这两个值就是装成功了的标志。

装好之后就不再依赖网络：断网也能打开，数据在独立存储里，也不受 Safari「7 天不访问就清数据」的影响。

**电脑**

Chrome / Edge 打开会看到地址栏右侧的安装图标，点它即可。

**不想托管，只想在局域网试**

```bash
cd daka-html
python -m http.server 8000
```

手机连同一个 WiFi，访问 `http://电脑IP:8000`。缺点是电脑得一直开着，IP 变了要重新输。

## 功能

- **清单**：换天（点箭头或左右滑）、点圆点打卡、长按弹操作表（完成 / 改名称时间 / 从这天移除）
- **任务库**：增删改；重复或单次；六种规则——每天、工作日、周末、法定上班日、休息日、自定义星期
- **批量导入**：一行一条，边打字边解析，分列「能识别」和「看不懂」
- **节假日**：粘贴区间自动铺开，驱动「法定上班日 / 休息日」两条规则
- **到点提醒**：页面开着时到点弹卡 + 提示音，可点「完成 / 稍后 10 分钟」，推满 3 次判失败
- **数据互导**：导出 / 导入 JSON

### 导入语法

```
早起 07:00 每天
喝水 09:30 工作日
游泳 15:00 周末
阅读 21:00 一三五
跑步 20:00 1-5
收邮件 09:00 法定上班日
大扫除 10:00 休息日
买牛奶 18:00 单日
冥想                      ← 不写时间默认 08:00、每天
```

以 `#` 或 `//` 开头的行当注释跳过。规则看不懂的行会被列出来，不会悄悄变成「每天」。

### 节假日语法

```
10月1日 休
2026-10-01 放假
10/1-10/7 休        ← 区间，整段铺开
10月11日 班         ← 调休补班
```

不写「班」就按放假处理；不写年份用今年，如果那天已经过去半年以上就自动算明年。

## 数据

存在 `localStorage` 的 `daka.web.v1` 键下，结构和 Android / iOS 版完全一致，可以直接互导：

```json
{
  "templates": [{ "id": "...", "name": "早起", "min": 420, "kind": "REPEAT",
                  "mode": "WEEKDAY", "days": 31, "created": 20779, "s": true, "v": true }],
  "days": { "20779": [{ "id": "...", "tpl": "...", "name": "早起", "min": 420,
                        "done": true, "dat": 400 }] },
  "holidays": [],
  "workdays": [],
  "seeded": true,
  "version": 3
}
```

`days` 的 key 是天序号（1970-01-01 = 0），`days` 位从 bit0=周一 到 bit6=周日。

## 目录

| 文件 | 作用 |
|---|---|
| `index.html` | 全部界面和逻辑，CSS/JS 内联 |
| `sw.js` | Service Worker，缓存外壳供离线打开 |
| `manifest.webmanifest` | PWA 配置，决定能不能装到主屏 |
| `icons/` | 主屏图标（180 给 iOS，192/512 给 manifest） |
| `.nojekyll` | 让 GitHub Pages 跳过 Jekyll 处理 |

## 已知限制

- **关掉页面就不会提醒**。iOS 不允许网页在后台定时响应，真正的后台推送要接 Web Push，而 Web Push 必须把网页装到主屏、并且有一台推送服务器，这个版本没做。
- **iOS 的 Web Push 横幅不能带操作按钮**，所以即使以后接了推送，「完成 / 稍后」也只能进 App 再点。
- **不能单独关震动**。iOS 不给网页这个权限。
- **没有同步**。数据只在这台设备的这个浏览器里，换设备要靠导出 JSON。
- **只在 Safari 里能装**。微信、QQ、抖音的内置浏览器都装不了，得复制链接到 Safari。

## 本地跑

不需要构建，没有任何依赖：

```bash
python -m http.server 8000
```

浏览器打开 `http://localhost:8000`。改了 `index.html` 刷新即可，`sw.js` 改了要重新打开一次页面才会更新缓存。
